# Provas Hospital Albert Einstein — Distrito Paulista RP

Sistema de processo seletivo fictício para GTA V/FiveM RP.

## Produção
- Frontend: Render Static Site
- Backend e banco: Supabase
- API: `exam-api`

## Recursos
- Cadastro com nome RP, ID da cidade, idade, telefone e Discord
- 12 questões objetivas + 3 discursivas
- Correção objetiva no backend
- Alternativas embaralhadas
- Consulta de resultado por ID da cidade + Discord
- Painel administrativo com aprovação, reprovação, notas e mensagem
- Liberação de nova tentativa
- Bloqueio de tentativa duplicada por ID ou Discord

> Projeto fictício para roleplay. Não possui vínculo com o Hospital Israelita Albert Einstein real.
